# MVP Requirements

## 1. User Input
The system should accept a complex business question from the user.

## 2. Question Understanding
The system should identify what the user is actually asking and break the question into smaller research questions.

## 3. Research
The system should collect relevant information from available sources.

## 4. Evidence
The system should store the important evidence and its source.

## 5. Analysis
The system should analyze the collected information and identify important findings.

## 6. Decision
The system should produce a recommendation based on the evidence.

## 7. Report
The system should generate a structured report containing:
- Recommendation
- Key findings
- Evidence
- Risks
- Assumptions
- Confidence
- Sources
